# Паспорт проекта


## 1. Название проекта

«Магазин обуви „Мадагаскар“»

## 2. Проблема

«У нашего магазина нет сайта и клиенты не могут посмотреть каталог товаров онлаен, надо научиться делать приложение»

## 3. Пользователи


«клиент — выбирает товар и оформляет заказ; продавец-консультант — ведёт каталог и остатки; администратор — управляет пользователями и правами».

## 4. Цель проекта
«дать клиенту возможность выбрать товар и оформить заказ онлайн, а продавцу — видеть актуальные остатки».

## 5. Метрики успеха

- время оформления заказа — < 2 минут;
- клиент находит товар через поиск/фильтры — за < 3 кликов;
- остатки обновляются сразу после продажи, без ручного ввода.

## 6. Границы (что НЕ делаем)

не подключаем реальные платёжные шлюзы (оплата — учебный симулятор); нет мобильного приложения - только сайт; доставка курьером не моделируется — заказ выдаётся в магазине.

## 7. Риски

не успеем метрики к дедлайну → приоритизация: сначала каталог и заказ, метрики в конце; сложно придумать 30+ товаров → берём реальный ассортимент из открытых источников
